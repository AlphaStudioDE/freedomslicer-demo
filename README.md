# FreedomSlicer public demonstration

This repository contains browser demonstration assets and the intentionally public author kit. The private application host and server-side module implementations are not included.

Version 0.0.6 includes an official free demo catalog, extension lifecycle management, an independent Model info example and a downloadable SDK. Purchases, accounts and production license enforcement are not enabled. User extension installation is through the official catalog.

The browser demo uses the open-source Kiri:Moto engine and Three.js. Their license notices are included with the deployed assets.
