# FreedomSlicer public demonstration

This repository contains browser demonstration assets and the intentionally public author kit. The private application host, store backend, credentials and server-side module implementations are not included.

The browser demo includes an official free catalog, isolated extension execution, lifecycle management, an independent Model info example and a downloadable SDK. Extensions cannot replace the platform store or sell modules through another store. Purchases and paid submissions are disabled. Local publisher accounts and operator review require the separate private backend.

The browser demo uses the open-source Kiri:Moto engine and Three.js. Their license notices are included with the deployed assets.
