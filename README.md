# FreedomSlicer public demonstration

This repository contains browser demonstration assets and the intentionally public author kit. The private application host, store backend, credentials and server-side module implementations are not included.

The browser demo includes a configurable official Store connection, isolated extension execution and lifecycle management. Accounts, catalog contents, developer tools and reviews depend on the selected private Store provider. The cloud edition supports account-page login handoff to Lite; sandbox research catalogs may instead include independent examples and an author kit. Extensions cannot replace the platform store or sell modules through another store. Purchases and paid submissions are disabled. External package intake and native engine delivery remain separate work; a catalog listing alone is not an installed engine.
